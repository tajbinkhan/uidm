**Release type:** first release (0.1.0)

The first public release of UIDM, a download manager written in Rust. It catches downloads in Chrome, Edge and Firefox, fetches each file over parallel connections, resumes after interruptions and keeps downloading after the browser closes. It runs on Windows, macOS and Linux.

## New

### Downloading
- Parallel connections per file. A connection that finishes early takes over half of the slowest range, which halved a throttled 4 MiB test download (8.0 s to 4.1 s).
- Resume after a crash, a lost connection or a restart. Partial files wait in a temporary folder.
- HTTP, HTTPS and FTP. Downloads started by a form are sent as the same POST.
- Streamed video (HLS and DASH) from a button over the video, with quality choice. With ffmpeg, streams are joined into one `.mp4`, and the sound can be saved alone.
- Speed limits for everything or for one download, a per-server connection limit, and a download quota (N MB every N hours).
- Proxies: HTTP, SOCKS4 and SOCKS5, auto-config scripts, a bypass list, a login per proxy, and Get System to copy the Windows setting.
- Site logins, which can cover a whole server or one folder. UIDM asks for a login when a server needs one, and refreshes expired links.

### Browser capture
- The extension hands downloads to UIDM in Chrome, Edge and Firefox, and translates into English, German, Spanish and French.
- Hold a key (or key combination) while clicking to skip or force capture.
- Context menu items for a link, all links on a page, or the links in selected text. You choose which items show.
- Address exceptions, offered after you cancel two save-as dialogs for the same site.
- A notice when UIDM cannot take a download, which gives the download back to the browser.

### Adding downloads
- Save-as dialog with category, a new category, and a description.
- Batches from a pattern, a text list, the clipboard or a drop target window.
- Import and export of plain lists and of IDM export files.
- A preview of the files inside a zip before you download it.
- Prompts when a file name is taken or a link is already in the list, with "Yes to all" for many files.

### Organizing
- Categories with their own folders, limited to certain sites if you want.
- Queues with a schedule that can repeat every N hours, and actions when a queue finishes: open a file, exit, sleep or shut down.
- The site grabber crawls a site with path, domain and size filters, signs in, finds links that scripts add, runs on a schedule, and can save a site for offline browsing. Projects and templates can be saved.

### The window
- Download list with search, sortable and resizable columns, per-connection progress, a Properties dialog, Open with... and Download again.
- A window for each download with status, Pause and Cancel.
- Tray icon, start with the system, notifications, sounds per event, a virus scan after download, themes, text size, and German, Spanish and French translations.
- UIDM checks GitHub for a newer release and can install it from inside the app.

### Systems
- Windows 10 and 11: installer (no administrator rights) and portable zip.
- macOS 11 or later: disk image for Apple Silicon and Intel.
- Linux: `.deb`, `.rpm`, AppImage and a `.tar.gz`.

## Fixed

These were found and fixed during development, before this release.

- **Security:** a stream download sent the page's cookies and Authorization header to every server its playlist named. They now go only to the playlist's own origin. (4355afc)
- **Security:** an `ftp://` address with `%0D%0A` in its path, user name or password could inject a second FTP command, such as `DELE`. Line breaks and NUL are now refused. (3c8296e)
- A download the daemon refused was lost after the browser's copy was cancelled. It now goes back to the browser with a notice. (#89, 483e677)
- The grabber's "All files to the folder of this category" listed files under the category but saved them in their own type's folder. (#95, 483e677)
- A partial file whose server date changed could not be resumed. An option now resumes it when the size and ETag still match. (#75, 73f6a77)
- Importing a list saved as UTF-16 failed. Both UTF-16 and UTF-8 are read now. (#82, 483e677)
- Grabber logins were kept per site only, so two projects on one site could not use different accounts. (#100, 483e677)

## Known limits

- Setup is not code-signed, so Windows SmartScreen and macOS Gatekeeper warn before it runs.
- The browser extension is loaded unpacked for now. The README's Install section has the steps.
- The Linux packages need glibc 2.35 and OpenSSL 3 (Ubuntu 22.04, Debian 12, Fedora 36 or newer).
